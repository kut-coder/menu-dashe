# Меню Даше

PWA для чтения недельного меню и списка покупок. Админ готовит меню (вручную или со скрина), проверяет и кнопкой **«Отправить меню пользователю»** публикует его Даше.

## Возможности

- Роли: **Админ** / **Пользователь**
- Меню по неделям и дням с датами (первая неделя: 02.11.2026–08.11.2026)
- Черновик → публикация только после «Отправить меню пользователю»
- OCR скрина → черновик в форму с ручной проверкой
- Список покупок: сумма одинаковых продуктов, магазины, сортировка, галочки «куплено»
- Темы: жёлтая, салатовая, голубая, розовая, сиреневая, белая, чёрная
- Обновление меню каждые 10 минут + кнопка проверки
- Установка на Android / iPhone как приложение (PWA), вход один раз

## Быстрый старт (локально без Supabase)

```bash
npm install
npm run dev
```

Демо-аккаунты:

| Роль  | Email             | Пароль  |
|-------|-------------------|---------|
| Даша  | dasha@menu.local  | demo123 |
| Админ | admin@menu.local  | demo123 |

Сид недели 02–08.11.2026 лежит как **черновик**. Зайдите админом → проверьте → **Отправить меню пользователю**.

## Два устройства (Даша + мама)

Нужен **один аккаунт пользователя** (например `dasha@…`) на обоих телефонах и **Supabase** (PostgreSQL). Тогда общее:

- меню, отправленное админом;
- галочки у продуктов;
- список покупок (магазины, «куплено»);
- вода и отметки тренировок.

Тема оформления остаётся своей на каждом устройстве.

Без Supabase данные живут только в памяти браузера телефона и **не синхронизируются**.

## Supabase + GitHub Pages

База — обычный PostgreSQL. Сайт собирается из GitHub и открывается через GitHub Pages. Бесплатного тарифа Supabase для семейного меню достаточно. Данные выгружаются стандартным дампом Postgres.

1. Создайте проект на [supabase.com](https://supabase.com). Регион — ближайший в Европе (например Frankfurt).
2. Authentication → Providers → Email: включите вход по почте и **выключите Confirm email**, иначе вход не пройдёт, пока письмо не подтверждено.
3. SQL Editor: вставьте и выполните `supabase/schema.sql`.
4. Authentication → Users: создайте `admin@…` и `dasha@…`. Почта, которая начинается с `admin@`, получает роль админа, остальные — пользователя.
5. Скопируйте `.env.example` → `.env.local`. Из Project Settings → API возьмите Project URL и `anon` `public` key.
6. В GitHub: Settings → Pages → Source = GitHub Actions; добавьте Secrets `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
7. Запушьте в `main` — workflow задеплоит сайт.
8. На обоих телефонах откройте сайт → войдите под **одним** логином Даши.

Для project-pages (репозиторий не `*.github.io`) в Actions уже прокидывается `VITE_BASE=/<repo>/`.

## Установка на телефон

1. Откройте сайт в Chrome (Android) или Safari (iPhone).
2. «Добавить на главный экран» / Share → Add to Home Screen.
3. Войдите под Дашей один раз — сессия сохранится.
